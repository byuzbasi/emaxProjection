# Plot the endpoint enclosure diagnostics

Shows outer bounds and feasible inner witnesses through the adaptive
search. This is a numerical convergence display, not a dose-response
confidence band.

## Usage

``` r
# S3 method for class 'emax_projection'
plot(x, ...)
```

## Arguments

- x:

  An \`emax_projection\` object.

- ...:

  Graphical parameters passed to \`graphics::plot()\`.

## Value

The input object, invisibly.
